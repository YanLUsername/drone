# drone
A 5in quadcopter drone.

### Features
- GPS for waypoint navigation
- Controlled via [ArduPilot](https://ardupilot.org/)
- Camera for POV view

### Hardware
- Matek F405-WMN Flight Controller
- 2.4G ExpressLRS Nano Reciever
- ESP32C3
- F1404 3800KV Motor
- 2200mAh 2S Battery
